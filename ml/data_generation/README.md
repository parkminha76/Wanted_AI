# ml/data_generation — 합성 데이터 생성

전체 파이프라인: **Faker + Custom Generator + 템플릿 합성 + 좌표기반 자동 라벨링 + Augmentation**

## 채워야 할 파일

- `faker_fields.py` — Faker(ko_KR)로 되는 필드 생성 함수 모음.
  이름/주소/전화번호/이메일/IP주소/날짜/회사명/주민등록번호(`fake.ssn()`)까지 커버됨
  (2026-09-08 직접 설치해서 확인함 — ko_KR 로케일에 ssn provider 있음).
- `custom_generators.py` — Faker에 없어서 직접 만들어야 하는 것: 운전면허번호,
  외국인등록번호, 사업자등록번호, 계좌번호(은행마다 자릿수 다름, `iban()`은
  유럽식이라 못 씀). **형식/체크섬 로직은 실제 유효한 예시로 검산 필수** —
  AI가 짜준 코드라도 그대로 믿지 말 것.
- `id_templates/` — 주민등록증·운전면허증 레이아웃 템플릿 이미지 (Figma나
  파워포인트로 그린 것). 실제 홀로그램·워터마크 디테일은 생략해도 됨.
- `synth_id_generator.py` — 템플릿 위에 값들을 정해진 좌표로 그려 넣는 합성 스크립트.

## 절대 빠뜨리면 안 되는 것 두 가지

1. **좌표 기반 자동 라벨링** — 값을 그리는 좌표를 그대로 YOLO 라벨(바운딩박스)로
   같이 저장해야 함. 이걸 빼먹으면 나중에 수천 장을 손으로 라벨링해야 하는
   최악의 상황이 됨.
2. **Augmentation** — 회전·기울임·밝기/대비 변화·블러·노이즈. 깨끗한 템플릿
   이미지로만 학습하면 실제 폰카메라로 찍은 사진에서는 잘 안 먹힐 수 있음.

## 얼굴 사진 / 서명란

실제 인물 사진을 쓰면 그 자체로 또 다른 개인정보 문제가 생김 — AI 생성 얼굴이나
실루엣 placeholder로 채울 것.

## 여기서 나온 데이터가 쓰이는 곳

- `ml/training/*` 의 모델 학습용 데이터
- `sample_data/` 의 데모 파일 (따로 손으로 만들 필요 없이 이 스크립트 재사용)
