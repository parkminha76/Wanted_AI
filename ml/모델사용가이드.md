# CNN(YOLO) 모델 핸드오프 가이드

작성: A · 대상: B (스캐너 엔진 통합 담당)

---

## 배경

ultralytics(YOLO)가 학습 시 자동으로 만드는 경로(`C:\wanted\runs\detect\infoguard_v1\weights\`)에
`best.pt`, `last.pt`가 그대로 있는 상태. 이 경로를 `.gitignore`에서 그대로 예외
처리하면, 나중에 재학습할 때마다 ultralytics가 `infoguard_v12`, `infoguard_v13`처럼
새 폴더를 자동 생성해서 경로가 계속 바뀌는 문제가 생김. 그래서 아래처럼
**의미 있는 고정 경로로 복사해서 관리**한다.

- `best.pt` — 검증(val) 성능이 가장 좋았던 시점의 가중치. **B가 실제로 로드해서
  마스킹/bbox 추출에 쓸 파일**
- `last.pt` — 마지막 epoch 가중치. 재학습(이어서 학습) 재개용, B의 추론엔 불필요

---

## 1. 가중치 파일 복사 (Windows PowerShell)

레포 루트(`C:\wanted`)에서 실행:

```powershell
mkdir ml\models -Force
Copy-Item runs\detect\infoguard_v1\weights\best.pt ml\models\infoguard_cnn_v1.pt
```

## 2. `.gitignore` 수정

기존 `*.pt` 관련 섹션(2번 — Python 섹션)에 아래 내용 추가:

```gitignore
# 학습된 모델 / 데이터 아티팩트 (용량 크고, 민감 데이터 섞일 수 있음)
*.pkl
*.pickle
*.joblib
*.h5
*.pt
*.onnx
# HuggingFace 계열 가중치 — NER 모델을 로컬에 받으면 이 형식으로 저장된다
*.bin
*.safetensors
/data/raw/
/data/processed/
/models/*.pkl
/models/checkpoints/
*.csv
!sample_data/**/*.csv
!/prompts/**/*.csv
sample_data/*_sample.png

# ultralytics(YOLO) 실험 산출물 전체 무시 — 중간 체크포인트, 로그, 재학습 실험본 등
# (레포 루트 기준 경로 — C:\wanted\runs\... 그대로)
runs/

# 단, B가 실제로 로드해서 마스킹/bbox 추출에 쓰는 최종 모델 파일만 예외.
# 이게 없으면 배포 서버/팀원 로컬에서 "모델 파일이 없다"는 사고가 남
# (7번 섹션의 샘플 PDF 예외와 같은 이유)
!ml/models/infoguard_cnn_v1.pt
!ml/models/fp_filter_v1.pkl
!ml/models/injection_classifier_v1.pkl
```

**핵심 원칙**: `*.pt`/`runs/`는 통째로 무시하되, 서비스가 실제로 로드해서 쓰는
"확정된 최종 모델 파일"만 이름으로 콕 집어서 예외 처리한다. 중간 체크포인트나
재학습 실험본까지 커밋되는 걸 막으면서도, 실제로 필요한 파일은 빠지지 않게 하는
방식이다.

## 3. B에게 전달할 코드

```python
from ultralytics import YOLO

model = YOLO("ml/models/infoguard_cnn_v1.pt")
```

경로가 고정돼 있으므로, A가 재학습을 몇 번 하든 B는 이 코드를 바꿀 필요 없다.

## 4. 재학습 시 반복할 작업 (A 담당)

회전/perspective augmentation 추가 등으로 재학습하면 ultralytics가 새 폴더
(`infoguard_v12` 등)를 만든다. 그때마다 같은 명령으로 덮어쓰기만 하면 됨:

```powershell
Copy-Item runs\detect\infoguard_v12\weights\best.pt ml\models\infoguard_cnn_v1.pt -Force
```
