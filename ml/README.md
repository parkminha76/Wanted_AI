# ml — 모델 학습

**담당: A (C가 인젝션 학습 데이터 생성 지원)**

이 프로젝트에서 "직접 학습시킨 모델"이라고 내세울 수 있는 부분. 심사 항목
"AI 활용의 적절성"이 여기서 갈린다 — 공개 모델만 조합하면 "그냥 ChatGPT에
시키면 되지 않느냐"는 질문에 답할 수 없기 때문.

## 하위 폴더

- `data_generation/` — 학습/데모용 합성 데이터 생성. 여기서 나온 데이터가
  `training/`의 모든 모델과 `sample_data/`의 데모 파일에 다 쓰임. **제일 먼저 손대야 함.**
- `training/`
  - `false_positive_classifier/` — 오탐 제거 분류기 (계좌번호 vs 주문번호처럼
    형태는 같은데 의미가 다른 값을 문맥으로 구분). AI DLP 업계 최대 약점을
    정면으로 겨냥하는 핵심 모델.
  - `injection_classifier/` — 한국어 인젝션 분류기 (문장이 "AI에게 내리는 명령"인지
    "문서 내용"인지 판별). 공개 데이터가 영어뿐이라 직접 구축해야 함.
  - `id_detector_yolo/` — 신분증 이미지용 CNN 객체 탐지기. COCO 사전학습
    YOLOv8n/YOLO11n을 파인튜닝. 처음부터 학습시키지 않음 — 백본은 재사용,
    커스텀 클래스 헤드만 직접 학습해서 성능 지표로 증명.
- `eval/` — 세 모델 공통으로 Precision/Recall/F1/오탐률 측정. 발표 슬라이드의
  "AI 활용 방식" 근거 수치가 여기서 나옴.
- `models/` — 학습된 가중치 저장 위치. 용량 크므로 `.gitignore` 대상.

## 공통 원칙

성능은 "쓸 만한 수준"에서 멈추고 지표만 기록 — 2주 안에 끝까지 튜닝하려 하지 말 것.
실제 개인정보/실제 신분증 이미지는 절대 쓰지 않는다.
