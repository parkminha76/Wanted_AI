# sample_data — 심사위원용 데모 파일

## 왜 필요한가

제안서 08 섹션 "함정 2": 심사위원은 파일을 직접 업로드하지 않는다. 첫 화면에
"샘플로 체험하기" 버튼을 넣어 클릭 한 번에 결과가 보이게 해야 함. 예선 배점의
투표 20%가 여기서 갈림.

## 최소 4개 필요

- 고객 명단 (이름/전화번호/주소 등 여러 필드 섞인 파일)
- 개발 문서 (API 키 노출 시나리오)
- 계약서 (사업자등록번호·계좌번호 등)
- 숨은 명령이 심긴 문서 (흰 글씨·폰트 크기 0으로 지시문 숨김)

전부 `ml/data_generation`의 Faker + Custom Generator로 만든 가짜 데이터만 사용 —
실제 개인정보는 절대 넣지 않는다.
