# prompts — Attacker AI / Defender AI 프롬프트 템플릿

**담당: C**

## 폴더

- `attacker/` — 사기꾼 역할극 프롬프트. 레벨별로 분리 (Lv.1~3 필수).
  상태머신이 대화 범위를 제한하므로, 프롬프트도 "자유 생성"이 아니라
  "이 시나리오 안에서만 말하기"로 설계.
- `defender/` — 대화 로그를 분석해서 취약 유형과 개선 포인트를 자연어로
  요약하는 프롬프트.

## 제일 먼저 할 일

**LLM 콘텐츠 필터 테스트 — 오늘 밤 안에.** "사기꾼 역할극"을 시키는 프롬프트가
후보 모델(OpenAI/Anthropic/Upstage 등)에서 실제로 거부당하는지 먼저 확인해야 함.
여기서 막히면 Attacker AI 설계 전체를 다시 짜야 해서 최우선순위.

## 두 기능이 연결되는 지점

Attacker AI가 생성한 한국어 공격 문장은 `ml/training/injection_classifier/`의
학습 데이터로도 재사용됨 — "사람을 속이는 AI로 AI를 속이는 문장을 만드는" 구조.
