# frontend — 전체 UI

프레임워크는 팀에서 정하는 대로 (React/Next.js 등 — 여기선 강제 안 함).

## 하위 폴더

- `src/scanner/` — 여러 파일 업로드 화면, 파일별 위험 점수 정렬 화면,
  숨은 명령 확인 팝업("이 문장을 제거하고 사본 만들기" / "무시하고 진행" /
  "이 파일 취소" 버튼 3개).
- `src/training/` — 레벨 선택 화면, Attacker AI 채팅 화면(실시간 스캔 경고
  UI 포함), 결과 리포트 화면(하단에 스캐너로 넘어가는 전환 버튼).
- `src/shared/` — 공통 컴포넌트.
