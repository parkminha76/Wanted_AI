# backend/training — 사기 대응 훈련 모드

Attacker AI와의 대화가 돌아가는 백엔드.

## 하위 폴더

- `attacker_ai/` — 상태머신 + LLM 호출. 자유 생성이 아니라 시나리오 범위를
  상태머신으로 제한하는 방식(라이브 데모 중 대화가 의도치 않게 새는 걸 막기 위함).
  `prompts/attacker/`의 프롬프트 템플릿을 여기서 불러다 씀.
- `levels/` — 레벨별 시나리오 설정 (Lv.1 택배·스미싱 / Lv.2 사내IT팀사칭 /
  Lv.3 거래처사칭 — 이 세 개가 필수, Lv.4~5는 여유 있을 때). 시나리오 대사는
  아직 구체화 안 됨 — `docs/final-direction.md`의 "아직 열려있는 것" 참고.

## 핵심 연결 지점 — 실시간 답장 스캔

사용자가 Attacker AI에게 답장을 보내기 직전, `backend/shared/` 계약대로
`backend/scanner`의 탐지 엔진을 호출해서 그 문장을 검사해야 함. 이게 두 기능을
잇는 핵심이라 빠뜨리면 안 됨 — 개인정보가 들어 있으면 전송 전에 경고하고,
그 행동을 훈련 점수에 기록.

## 결과 리포트

대화 로그를 분석해서 어느 턴에서 흔들렸는지, 어떤 유형에 약한지 요약하는
Defender AI 부분도 여기 포함. 리포트 화면 하단에 스캐너로 넘어가는
전환 버튼 연결은 프론트(D)와 협의.
