# backend/scanner — 정보유출 스캐너 엔진

파일을 넣으면 탐지 결과가 나오는 백엔드. `backend/shared/`에서 정한 계약을 구현하는 쪽.

## 하위 폴더

- `parser/` — 문서 파싱 & 라우팅. 입력이 텍스트가 있는 문서(PDF/워드)인지,
  이미지(신분증/스캔본)인지 먼저 구분해서 각각 다른 파이프라인으로 보내야 함
  (`docs/final-direction.md`의 "이미지/텍스트 하이브리드 파이프라인" 참고).
- `detectors/` — 실제 탐지 로직. 정규식(형식 고정 필드), 한국어 NER(이름/주소/조직명),
  숨은 문자 탐지(흰 글씨·폰트0·제로폭), 오탐 제거 분류기 연동, CNN 신분증 탐지기 연동이
  다 여기 모임. `ml/`에서 학습된 모델을 갖다 쓰는 자리.
- `masking/` — 탐지된 필드를 실제로 가리고 마스킹된 안전 사본을 만드는 부분.
  원본은 절대 건드리지 않고 사본만 생성.

## 잊지 말 것

- 업로드 파일은 처리 후 즉시 폐기 — 저장하면 안 됨 (개인정보 보호 서비스가
  개인정보를 모으면 그 자체로 실격 사유).
- 외부 LLM에 설명 생성을 맡길 때도 마스킹된 텍스트만 전달.
- 필드는 하나로 뭉치지 말고 종류별로 따로 탐지 — 계좌번호 vs 주문번호처럼
  헷갈리는 쌍이 필드마다 있을 수 있어서, 오탐 제거 분류기도 필드별로 검증 필요.
